# 机械建模与构图：检查的是观众看见的东西

## 先建立装配图

列出主体、功能零件、支点和连接点。踏板总成至少有安装支架、轴、曲线臂、踏面与动作关系；液压机构要让推杆接到活塞；车轮的辐条和轮毂共用中心。先给这些坐标一个稳定参照，再加装饰、破坏和粒子。

抽象几何是构造手段。挤出曲线轮廓、倒角、不同厚度、橡胶肋、螺栓、孔洞和强化结构共同给物体可辨认性。并非每个资产都需要完整工程 CAD，但关键功能不能靠字幕补救。

## 语义与材质

同一件模型转五个角度不等于五个时期。木块要有木体与摩擦面；冲压板件有板厚、折边或压筋；纤维复合材料可用铺层与筋展示；传感器有本体、接口和感测关系。

从主题选择有限配色，建立深浅面与明确轮廓。暗模型放在暗底容易失去识别性；给材料与功能分区，而不是无差别发光。科研示意和真实试验照片分开标注。

## 按目标相机检查

世界空间没有碰撞，屏幕上仍会挡字。把文字区域、模型区域与说明区域分开；模型按最终投影的边界适配，留出动作极值的余量。横向填满一个区域时，也要检查完整高度与连接件。

相机转角之后，重新检查轮毂、支架孔、连杆和踏面能否看懂。模型不能因持续平移逐步出框；真正需要旋转的轴不要用屏幕二维旋转替代。

## 几个容易漏掉的状态

- 踩下最大角度时，踏面是否穿过地板或遮住下方文字。
- 爆炸图最分散时，零件和引线是否仍在安全区。
- 断裂碎片是否进入正文区域；破坏示意是否被误认为实际断裂原因。
- 轮播一半时，新旧模型与文案是否叠在同一位置。
- 胶片移动时，齿孔、边界和片格是否使用同一位移。
- 打字与回删时，光标是否在真实字宽处移动，而不是整行每次重新居中。

按这些状态抽帧，不只选最漂亮的一帧。判断不通过时优先修改模型结构、相机或版式，不先加更多后期效果。
