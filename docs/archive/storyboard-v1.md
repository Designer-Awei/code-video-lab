# 分镜与画面设计：《一块踏板，一百四十年》

## 总体设计

**一句话**：一块踏板穿过 140 年，每到一个时代，就换上那个时代的"画法"。

**贯穿母题**
1. **主角踏板**：同一个踏板轮廓出现在每一章，造型随时代变（拉杆 → 木块 → 铸铁踏板 → 冲压钢板 → 复合材料 → 一束信号）。章节之间的转场都从这块踏板"长出来"：踏板压下去，画面就换一个时代。
2. **力的读数**：右下角的牛顿读数 `____ N` 是一条暗线。冷开场从 0 冲到 1612N 后定格；第 6 章回来做 500 / 1500 / 1612 的对比；第 7 章读数变成一条电信号波形。
3. **一道裂纹**：冷开场的断裂裂纹，在片尾回放成一条"时间线"，把 1886→2026 串起来。

**画风随时代演变**（每一帧都由代码生成，不用任何下载素材）

| 章节 | 时代 | 画面语言 | 主色 | 技术 |
|------|------|----------|------|------|
| 冷开场 | 2026 | 高速摄像机质感：暗场、冷灰、单一警示红；示波器式力曲线 | `#0E1013` / `#C9CED6` / `#E8412C` | Three.js 踏板总成 + Canvas HUD + 胶片颗粒着色器 |
| 2 | 1886–1888 | 铜版画 / 专利图：米黄纸、排线阴影、墨线逐笔画出 | `#EDE3CC` / `#2A2118` / `#8C2F1B` | Canvas 2D 排线 + 纸纹着色器 |
| 3 | 1896–1908 | 工程蓝图：普鲁士蓝底、白色细线、尺寸标注、爆炸图 | `#123A6B` / `#E8F0FA` | SVG 描线 + Canvas |
| 4 | 1921–1930s | Art Deco 海报 + 剖面图：液体在管路里流动 | `#F2E6CF` / `#151515` / `#C8A24A` | Canvas 粒子流体（伪 2D）|
| 5 | 1950s–1978 | 中世纪赛车海报（平涂 + 网点）→ ABS 段落切到 CRT 示波器 | `#F4EBDD` / `#1F5F4A` / `#D9472B`；CRT `#7CFFB2` | Canvas 平涂 + 网点着色器 + WebGL CRT |
| 6 | 2000s– | CAD / 有限元：线框踏板、应力云图从蓝到红 | `#0B0D10` / `#2B6CFF→#FF3B2F` 色带 | Three.js 线框 + 应力着色器 |
| 7 | 2001–2026 | 数据可视化：踏板溶解成信号脉冲，沿线路跑向四个车轮 | `#05070A` / `#4BE1FF` / `#FFFFFF` | Canvas + WebGL 辉光（克制使用）|
| 8 | 1886→2026 | 回顾蒙太奇：7 种画风踩着鼓点快切，最后收回单一踏板 | 混合 → 冷开场色板 | 复用前面所有场景 |

**禁止清单**：居中大字 + 渐变背景的默认风格；所有元素一起淡入淡出；角落里多余的标签、边框和装饰性发光；满屏小字；用代码仿画尊界车辆或品牌 Logo（要出现就用真实截图）。

**真实截图（唯一的例外）**：涉及尊界事件的事实陈述（测试画面、官方回应、媒体报道、标准条目）一律用真实截图，文件在 `source/screenshots/`，网址和截图时间登记在 `sources.json`。呈现方式：截图像一张纸放在冷开场的暗场里，镜头缓慢推近到关键句，关键句用红色下划线逐字划出；每张截图左下角固定标注"来源：xxx · 2026.10.08"。截图不加滤镜、不改字、不裁掉日期和来源。

**文字规则**：中文标题用一种黑体（HarmonyOS Sans SC Bold），年份和数字用一种等宽字体（Cascadia Mono），每段屏幕字至少停留 2.5 秒，同屏不超过 12 个汉字。

**镜头**：每个镜头都要有运动（推、拉、跟随、绕转），主体占画面 50% 以上。

## 声音设计

- **配乐**：全部用 Python（numpy）合成，不用采样和音频文件。主调 D 小调，84 BPM（一拍 0.714 秒），每章一个音乐段落，跟着画风换配器：
  - 冷开场：低频持续音 + 心跳式底鼓 + 逐渐升高的张力音，"啪"之前抽空 0.5 秒，然后重击；片名处第二次重击
  - 第 2 章：拨弦 + 弦乐铺底（八音盒感）
  - 第 3 章：钟表式机械打击乐，齿轮咔哒声落在拍子上
  - 第 4 章：低音提琴式贝斯行走 + 温暖铺底
  - 第 5 章：节奏推进，铜管式合成器；ABS 段落换成 8-bit 方波脉冲
  - 第 6 章：极简脉冲，张力累积，在"这就是一块踏板的分寸"处解决到大三和弦
  - 第 7 章：琶音合成器，电子质感
  - 第 8 章：全编制推高到高潮，最后只留一个单音
- **人声**：【Awei 原声】8 段，放在音乐上方。人声出现时配乐自动压低（侧链闪避约 -10dB），章节之间留 2–4 秒纯音乐过渡，画面切换落在这段过渡的重拍上。
- **音效**（代码合成）：断裂"啪"、金属咔哒、皮革摩擦、齿轮、液体流动、CRT 嗡声、数据提示音。每个音效对齐到画面动作发生的那一帧。
- 混音整体响度 -14 LUFS，人声峰值不超过 -1 dBTP。
