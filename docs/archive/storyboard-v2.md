# 分镜 v2：画面与动效升级

> v1（`storyboard.md`）的叙事和镜头顺序保留；v2 解决的问题是"讲解元素太简单"。参考 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15) 的做法：每章对应一种**标准 MG 风格**，把它的标志技法写成能检验的数字，按秒排出钩子 → 升级 → 高潮 → 定版。参考缓存已清理，按上面的原仓库链接查阅。

## 全片动效规范（每章都检查）

| 规范 | 数值 |
|---|---|
| 弹簧四档（`L.SP`） | 指示条/锁定框 `snap` w24 z0.8；卡片/镜头 `card` w15 z0.72；3D 物体/大字定版 `heavy` w10 z0.92；贴纸/碎片 `bouncy` w18 z0.45 |
| 入场 | 预备（反向 4–6%）→ 冲出 → 回弹 → 落定；同组元素错峰 2–4 帧（0.067–0.133 s），同一时刻只让一个主体动 |
| 3D 镜头 | 长尾缓动：前 20% 时间走完 80% 路程（`1-(1-x)^4`）；镜头永不完全静止，叠 0.3% 幅度的手持噪声 |
| 文字 | 一律遮罩上滑出字（`L.maskText`），出场向上滑出；禁止淡入淡出整屏文字 |
| 数字 | 滚动 3–5 帧随机值再落定真实值；单位与数字字号比 1:2 |
| 硬事件帧 | 断裂、锁定、盖章这类瞬间：白闪 1 帧（1.0）+ 下一帧 0.3；色差 0.003 × e^(−7t) 衰减；镜头震动 e^(−8t) |
| 转场 | 由元素带走画面（踏板压下、液体漫过、线条延伸、形变），不用交叉淡化 |
| 定版 | 每章最后一个画面停 0.8–1.2 s，保留微动（呼吸缩放 0.5%、光扫） |

## 各章风格与标志技法

| 章 | 标准风格 | 3D / 主体 | 标志技法（可检验） |
|---|---|---|---|
| 1 冷开场 | **电影级 CGI + 取证 HUD**（Territory Studio 克制版） | Three.js 程序化踏板总成：冲压支架、转轴、踏板臂、橡胶踏面、推杆、脚坑；支架沿锯齿裂纹拆成上下两块 | 光扫揭示（0.5 s 内出钩子）；HUD 线框按层级错帧描出；读数滚动后落定；锁定框 1.4→1.0 吸附断口；断裂帧白闪 + 色差 + 震动 + 碎片抛物线 + 0.35× 慢放；报道截图像纸片落在暗色桌面上（真实阴影） |
| 2 1886 | **线描一笔画 + 3D 铜版画排线** | 3D 奔驰专利车，屏幕空间三层交叉排线着色器 + 墨线描边 | 墨线按部件逐笔画出（`cubic-bezier(0.65,0,0.35,1)`），镜头跟随笔尖；线转面：描完轮廓后排线从暗部生长；红线是力的路径；Bertha 段用 3D 排线地形 + 路线描出 |

| 4 1921–1930s | **液体动效 + Art Deco** | 玻璃主缸、透明油管、四个轮缸活塞；真空助力器剖面 | 刹车油沿管路"流"满（前沿有 3–5 个错相位的鼓包）；活塞被推出时回弹 2–3 帧；章节入场用波浪前沿液体擦除 |
| 5 1950s–1978 | **中世纪赛车海报（平涂 + 网点）** | 卡通分层着色的赛车与通风刹车盘，网点后期；DS 蘑菇按钮；双回路；ABS 车轮 | 刹车盘烧红（自发光 + 辉光，不是界面发光）；平涂色块、旋转网点；入场 `cubic-bezier(0.34,1.56,0.64,1)` 式回弹；10% 挤压拉伸 |
| 6 2000s– | **3D 产品渲染 + 有限元** | 同一主角踏板换成玻纤尼龙版本；应力云图；纤维微观阵列 | 克隆阵列（纤维 / 网格单元按波浪相位起伏）；应力色带从蓝到红按载荷生长；溃缩时支架解锁的慢动作 |
| 7 2001–2026 | **形变叙事 + 数据 HUD** | 底盘线框；中央制动单元按年代形变：ECU+液压 → 电机助力 → 一体式 → 四个电机卡钳 | 形变走"A → 胶囊 → B"两段各 8–12 帧，中段最快 `cubic-bezier(0.7,0,0.3,1)`；信号脉冲沿线跑到车轮 |
| 8 收尾 | **形变链 + 定版** | 演化链：杠杆 → 木块 → 钢踏板 → 复合踏板 → 传感器；最后回到主角踏板 | 每拍一次形变；红色裂纹拉直成时间轴；片名定版 = 封面构图，停 1.2 s 带光扫微动 |
