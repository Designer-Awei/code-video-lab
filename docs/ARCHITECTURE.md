# 代码导览：把机械、美术和时间接起来

## 两层画面，一个时间入口

案例 `index.html` 的两个画布分别承载 WebGL 与 Canvas。入口 `window.render(t)` 找到时间轴中的章节，调用 `SCENES[n].render(ctx, chapterTime, chapter, absoluteTime)`。正文内部的 `t` 和最终加封面后的成片时间不可混用。

`src/lib.js` 负责闭式弹簧、固定种子随机、遮罩文字、卡片和转场。转场先把每个镜头的 3D 与 2D 层拍平，再合成两张离屏图，因此不会丢掉 WebGL 主体。`STAGE.used` 决定当前是否显示 3D 画布。

初始化会建立几何、材质和缓存纹理。每次 render 要重新设定本帧的位置、角度、可见性、载荷和文字状态；切回任意时间也应得到相同结果。不能用“上一帧角度加一点”模拟踩踏、粒子或相机。

## 优先阅读顺序

1. `src/scenes/ch1.js`：新闻进入、踏板动作与断裂、事实图像和机械示意的角色划分。
2. `src/three/models_pedal.js`：`M.pedal()` 中的总成结构、转轴、曲线踏板臂、踏面、加强筋、推杆、螺栓和断裂分组；`setPress`、`setBreak` 如何从时间设置姿态。
3. `src/scenes/ch2.js` 与 `src/three/models_history.js`：专利车、轮子、杠杆和铜版画风格的共同构图。
4. `src/three/stage.js`：墨线、排线、网点、胶片与金色 Art Deco 背景。先看相机和 pipeline，再看后期着色器。
5. `src/lib.js`：spring/track、maskText、capture/transition/sequence。理解投影与版式后，再移植动效工具。
6. `src/three/models_era.js`：Velo、Model T、盘式、鼓式、液压管路、助力器、车轮、底盘和蘑菇按钮。
7. `src/scenes/ch8-art.js` 与 `ch8.js`：针对具体名词新画资产、按边界适配片格、上下轮播、独立打字机结尾。

## 程序化建模的有效粒度

把物体拆为“能解释功能的零件”，而不是把全部形状抽象为细长盒子。踏板臂要弯曲、踏面有面宽和摩擦纹、支架有安装孔和厚度、推杆从有效连接点出发。轴和孔洞定义旋转中心，材料的厚度与加强筋定义受力语言。

`M.cyl(a,b,r,mat)`、轮廓挤出和 rounded geometry 是构造工具；它们不自动保证机械合理性。装配完成后在目标相机下检查，再检查踩下、回弹、拆解和破坏的极值姿态。

案例模型是科普示意，不是尺寸精确的制造 CAD 或真实有限元计算。应力色带、液体前沿和断裂动作服务于原理解释，不把它们当作实测结果。

## 美术不是最后加的滤镜

第一章的暗场产品感、第二章的铜版画排线，以及后续金色背景，都通过模型材料、光源、轮廓、画面层级和相机共同建立。仅给粗糙块体套 shader，无法得到同样效果。

保持“实物结构＋有限配色＋明确主次”。墨线与排线应帮助辨认表面转折，模型边缘不能被装饰线吞掉。文字不使用全屏一起淡入，也不自动套带填充的矩形；其版式要在最终投影上评审。

## 声音与画面的接口

`timeline.json` 保存章节范围、vo_start、vo_end、vo_duration 和口播文本，`src/timeline.js` 是浏览器版本。第一章另有人工整理后的 cues；许多后续镜头仍用字符比例的 `L.anchor` 估算短语位置，不能把它描述成逐字时间戳。

`tools/reorder_vo.py` 展示停顿检测、设计气口和第一章叙事重排；它的分组是案例特定的。`tools/build_timeline.py` 适用于新制作的时间轴，不适合直接拿来改变已审核成片。

`tools/replace_voice.py` 适用于同文案换声：MFCC 归一化、单调 DTW、匹配静音区、保持音高的 atempo 和气口样本保留。它依赖原录音及新录音，不做转录，也不能发现所有误读。人工试听关键短语仍有价值。

## 输出与缓存边界

`previews/` 是当前方案的审片工作区，`qa/` 是验证记录，`out/` 是分章片与交付。都属于可再生本地产物；精选画面单独进入 `docs/gallery/`。

文件大于 10KB 不能证明渲染成功。章节缓存必须检查编码、分辨率、帧数和时长；正式文件先渲到临时目标，验证后再替换。换配音时复制视频流，再比较编码包哈希，确认画面未变。
